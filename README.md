## 📋 Overview

TimeTravel is a web CTF challenge that involves time-related logic, potentially including race conditions, JWT expiration, token manipulation, or other time-based attacks.

## 🚀 Quick Start

```bash
git clone https://github.com/Pytech04/TimeTravel.git
cd TimeTravel
npm install
npm run dev
```

## 🛠️ Tech Stack

- TypeScript
- Vite
- Tailwind CSS
- Client/Server components

Time-based web exploitation techniques.
