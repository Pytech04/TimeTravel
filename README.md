## Overview

Web CTF challenge exploring time-based vulnerabilities - including logic flaws, race conditions, token expiration, and timing attacks.

## Structure

- `client/`, `server/`, `shared/` - Fullstack app structure
- TypeScript + Vite frontend with Tailwind CSS
- Drizzle ORM configuration

## Getting Started

```bash
git clone https://github.com/Pytech04/TimeTravel.git
cd TimeTravel
npm install
npm run dev
```

## Focus Areas

- Time-based logic flaws
- Race conditions
- JWT/Session timing issues
